# 📱 Nice-Gadgets-Store 

A modern mobile product catalog built with React and styled from high-quality Figma designs. Allows users to browse, sort, and manage phones, tablets, and accessories with a responsive interface and smooth UX.

| Technology       | Description                                       |

## ✨ Features

- 🔍 Product sorting (by price, name, newest)
- 📱 Browse categories: Phones, Tablets, Accessories
- 🔁 Pagination with adjustable items per page
- 🧭 **Breadcrumbs** for better navigation
- ❤️ Add/remove products to/from Favorites
- 🛒 Add/remove products to/from Cart
- 🎨 Dark/Light theme switcher based on own design
- 💾 Persistent state using LocalStorage
- ⚡ Skeleton loaders for better loading experience
- ⬆️ Scroll-to-top button
- 🧩 Modular, clean folder structure

---

To run this project locally:

```bash
1. Clone the repository:
git clone https://github.com/Yaroslav65/Nice-Gadgets-Store.git
cd Nice-Gadgets-Store

2. Install dependencies:
npm install

3. Run the project locally:
npm start
```
